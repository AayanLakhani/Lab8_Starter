# Lab8-Starter

Group: Aayan Lakhani

Service workers help implement graceful degredation by allowing assets to be cached, so that if no network is available, the web app is still able to function. In normal operation, they don't provide much value, as fetching network requests is easy if the network is fast and reliable. However, since we can't control the network, it's a good idea to allow network problems to be gracefully handled, and to add functionality so that the web app isn't completely useless with a slow or even nonexistent network connection.
